---

# Project Overview

Credit card fraud causes significant financial losses for institutions and customers. Traditional rule-based systems often struggle to detect evolving fraud patterns and may generate high false positives.

This project builds an intelligent fraud detection system capable of classifying transactions as:

* **0 → Legitimate Transaction**
* **1 → Fraudulent Transaction**

The system prioritizes:

* Improving prediction reliability
* Minimizing missed fraud cases
* Providing interpretable risk assessment

# Feature Engineering

Additional behavioral features were created to improve fraud detection performance before model prediction.

### 1. High Risk Transaction (`high_risk_transaction`)

This feature is generated when a transaction is:

- International (`foreign_transaction = 1`)
- From a mismatched location (`location_mismatch = 1`)

Logic:

```python
if foreign_transaction == 1 and location_mismatch == 1:
    high_risk_transaction = 1
else:
    high_risk_transaction = 0
```

### 2. Night Transaction (`night_transaction`)

This feature identifies transactions occurring during late-night hours, which may indicate higher fraud risk.

Logic:

```python
if transaction_hour >= 22 or transaction_hour <= 4:
    night_transaction = 1
else:
    night_transaction = 0
```

These engineered features help the model identify suspicious transaction patterns more effectively.

# Models Evaluated & Final Selection

Multiple ensemble paradigms were rigorously benchmarked to identify optimal detection boundaries:

* **Random Forest Classifier** (Baseline Bagging Paradigm)
* **Gradient Boosting Machine (GBM)** (Sequential Boosting)
* **XGBoost** (Optimized Extreme Gradient Boosting)

### Final Selection Verdict: XGBoost

XGBoost delivered the strongest overall performance metrics. Optimization hyper-parameters focused heavily on maximizing **Recall** and **ROC-AUC** scores to keep the system highly sensitive to missed fraud patterns.

# Risk Classification Engine

Predictions are mapped to risk levels based on fraud probability scores generated by the model.

| Fraud Probability | Risk Level | Classification |
|-------------------|-------------|----------------|
| ≥ 70% | 🔴 High Risk | Fraudulent |
| 20% – 69% | 🟠 Medium Risk | Suspicious |
| < 20% | 🟢 Low Risk | Legitimate |
